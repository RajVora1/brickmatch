# BrickMatch API

The part of [BrickMatch](https://github.com/RajVora1/brickmatch) that runs the trained models: it finds and names
the pieces in a photo, and draws step-by-step instructions, booklets and 3D views. The website calls it.
Opening this Space also shows the full website.
